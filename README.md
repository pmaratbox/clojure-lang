# clojure-lang

Incremental lessons learning Clojure.

## Prerequisites

- Clojure CLI
- JDK 11+ (`brew install --cask temurin` on macOS, or `sudo apt install default-jdk` on Debian/Ubuntu)

### Install Clojure CLI

- macOS (Homebrew): `brew install clojure/tools/clojure`
- Linux: follow the [official install script](https://clojure.org/guides/install_clojure)

### Verify

    clojure --version

## Lessons

- [0001-hello-world](0001-hello-world/) — print "Hello, world!"
- [0002-variables-and-types](0002-variables-and-types/) — declare and print an int, float, string, and bool

## How to run

See each lesson's `README.md` for the exact command.
