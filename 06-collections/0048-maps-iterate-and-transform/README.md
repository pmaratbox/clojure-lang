# 0048 — Maps: Iterate & Transform

Build a map from letters to numbers (`a`->1, `b`->2, `c`->3), sum all its values, and print `sum: 6`. `(vals m)` returns the map's values and `reduce +` folds them. `keys`, `vals`, and iterating the map (which yields `[k v]` pairs) are the traversal options; maps are immutable.

## Run

    clojure -M main.clj
