# 0007 — Collections

Build a vector of the integers `1, 2, 3, 4, 5`, then print its count and its
first and last elements. `[1 2 3 4 5]` is a vector (whitespace separates
elements — no commas needed). `count`, `first`, and `last` are plain functions,
not methods, and the collection is immutable and persistent. `println` inserts
a space between its arguments, producing `count: 5`.

## Run

    clojure -M main.clj
