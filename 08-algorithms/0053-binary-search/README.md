# 0053 — Binary Search

Binary-search the sorted array `1, 3, 5, 7, 9` for `7` and print the index where it is found: `found 7 at index 3`. `loop`/`recur` carries `lo` and `hi`; `(nums mid)` indexes the vector by calling it as a function, and `quot` is integer division. `cond` picks the branch.

## Run

    clojure -M main.clj
