# 0051 — Ternary & Conditional Expressions

For each of `4` and `7`, choose `even` or `odd` with a single conditional expression and print `4: even` and `7: odd`. Clojure's `if` is an expression returning one branch: `(if cond a b)`. With no statements in the language, every form yields a value, so no separate ternary is needed.

## Run

    clojure -M main.clj
