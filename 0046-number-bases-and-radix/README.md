# 0046 — Number Bases & Radix

Print the integer `255` in hexadecimal, octal, and binary, producing `hex: ff`, `oct: 377`, and `bin: 11111111`. `(Integer/toString n radix)` via Java interop renders the integer in the given base; radix 16, 8, and 2 produce hex, octal, and binary strings.

## Run

    clojure -M main.clj
