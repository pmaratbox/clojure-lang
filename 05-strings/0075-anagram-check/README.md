# 0075 — Anagram Check

Check whether each pair is an anagram by comparing sorted letters — `listen`/`silent` and `hello`/`world` — printing `listen/silent: yes` and `hello/world: no`. `(sort a)` sorts a string into a seq of characters; comparing the two sorted seqs with `=` tests the anagram.

## Run

    clojure -M main.clj
