# 0002 — Variables & basic types

Bind four top-level vars to values of Clojure's four corresponding host
types (long, double, string, boolean) — Clojure is dynamically typed, so
no annotations are needed. `println` separates its arguments with a single
space, which gives the `label: value` layout without explicit interpolation.

## Run

    clojure -M main.clj
